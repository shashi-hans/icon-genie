Every icon you need, and the tools around them

A tree-shakeable React library with a searchable gallery, an AI generator for the icons that do not exist yet, and a resizer for everything else.

Icon Gallery

Search every icon, switch between thin, regular, fill and duotone, set a size and colour, then copy the import line.

Icon Generator

Describe an icon and get one drawn. Free with no account, with your own API key, or from your own browser AI chat.

Icon Resizer

Drop in an SVG or PNG, pick the sizes you need, and download them. The file never leaves your browser.

Icon Theme

New

Fetch a website's theme colour. Get every icon from Gallery and Generator in same theme colour.
